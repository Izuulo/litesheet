# Contributing

## Setup

Node (version in `.nvmrc`) and [pnpm](https://pnpm.io), then:

```bash
pnpm install
pnpm dev
```

## Before opening a pull request

```bash
pnpm lint
pnpm check
pnpm test
```

- Use [conventional commits](https://www.conventionalcommits.org): `feat:`, `fix:`, `chore:`, `docs:`, `test:`.
- UI changes need screenshots and an updated design canvas.

## Bug reports

Please **attach the Litematica export file** that caused the problem, and say which browser,
Litematica version, Minecraft version and game language you use. Most bugs can't be reproduced
without the file.
